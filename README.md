# zenvara-platform/homebrew-tap

Official Homebrew tap for Zenvara command-line tools.

## Usage

```sh
brew tap zenvara-platform/tap
brew install zen
```

or in one line:

```sh
brew install zenvara-platform/tap/zen
```

## Formulas

| Formula | Description |
|---|---|
| [`zen`](Formula/zen.rb) | The Zenvara CLI — installs, runs, and operates a Zenvara instance. |

Formulas are generated and updated automatically by the [zen release pipeline](https://github.com/zenvara-platform/cli); do not edit them by hand.
